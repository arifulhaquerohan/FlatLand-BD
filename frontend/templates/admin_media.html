Turn on the CDN in four steps

Ten minutes, once. Nothing breaks while it is off.

  1. Create a free account. 25 GB storage and 25 GB monthly delivery, far more than this site needs. Sign up
  2. Copy three values from Settings then API Keys: cloud name, API key, API secret. Open API keys
  3. Paste them into your .env file next to wsgi.py, then save. 
    CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=123456789012345
CLOUDINARY_API_SECRET=your-secret
CLOUDINARY_FOLDER=flatlandbd/uploads
MAX_UPLOAD_MB=24
  4. In cPanel, run Pip Install and then Restart. Come back here and press Run connection test. Green means done.

What happens automatically

  • Every upload is converted to WebP and capped at 1600px, so a 6 MB phone photo becomes a few hundred KB.
  • Visitors receive a size that matches their screen, chosen from a srcset.
  • Deleting a listing or a gallery photo also deletes the file from storage, so nothing is orphaned.
  • If Cloudinary is unreachable mid-upload, the photo is saved locally instead of being lost.
